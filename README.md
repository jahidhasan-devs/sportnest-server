# 🏟️ SportNest Backend

This is the backend API server for SportNest - Sports Facility Booking Management System.

---

## 🚀 Technologies Used

- Node.js
- Express.js
- MongoDB
- MongoDB Atlas
- CORS
- dotenv

---

## ✨ Features

- Create and manage sports facilities
- Get all facilities
- Get facility details by ID
- Add new bookings
- Get user bookings
- Cancel bookings
- Update facility information
- Delete facilities
- MongoDB database integration
